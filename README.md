# ITCS-3112-Project

    Install the Extension. 
• Open VS Code, go to the Extensions view (Ctrl+Shift+X or Cmd+Shift+X), search for C# Dev Kit (published by Microsoft), and install it. This automatically bundles the base C# language extension.

    Install the .NET SDK.
• Open the Command Palette (Ctrl+Shift+P or Cmd+Shift+P), run Welcome: Open Walkthrough, and select Get Started with C# Dev Kit to install the .NET SDK. Alternatively, download it directly from the Official .NET Website.
